# TEMO Efficiency v1.5.0 — Provider-Aware Execution Routing

TEMO Efficiency v1.5.0 expands the original model-routing workflow into a portable, provider-aware execution behavior contract.

## Highlights

- Shows the recommended **Tool + Model + Profile + Level + Boost + Consumption + Deploy + Reason** before every executable command.
- Discovers the user's real AI/provider environment instead of assuming a fixed model catalog.
- Supports ChatGPT/OpenAI, Codex, Claude/Claude Code, Gemini, Cursor, Copilot, Cloud Code, local models, and other AI tools.
- Requests screenshots or exact pasted labels when the current model/level catalog cannot be verified.
- Introduces a **Catalog Confidence Gate** to block fabricated model ladders.
- Uses `CURRENT_MODEL_ONLY` when only the active model is known.
- Flags catalog fabrication as `CATALOG_HALLUCINATION_FAIL`.
- Adds a self-contained `TEMO_PORTABLE.md` for AI environments with weak/no GitHub browsing.
- Falls back after one failed GitHub lookup instead of repeatedly searching/indexing.
- Adds cross-device/provider verification tests.
- Adds `TEMO_LATEST.md` and a once-per-session canonical refresh check.
- Adds opt-in feedback with a GitHub issue form and no silent telemetry.
- Expands Arabic and English documentation.

## Execution flow

```text
Load / refresh TEMO Efficiency
→ identify/confirm provider/tool
→ verify actual selectable models + reasoning levels
→ request screenshots/list only if needed
→ build/reuse FAST / BALANCED / DEEP / MAX from verified choices
→ score the current checkpoint
→ show EXECUTION CHOICE
→ execute one bounded micro-checkpoint
→ verify acceptance
→ LOCKED_PASS
→ escalate one step only if evidence requires it
→ optionally prepare feedback
```

## Portability

TEMO now has three supported access paths:

1. Full canonical repository access.
2. Raw portable fallback: `TEMO_PORTABLE.md`.
3. Uploaded/pasted portable file when external web access is unavailable.

## Catalog integrity

A provider name, plan/tier, or one active model is not enough to prove the full selectable model catalog. Exact ladders must be based on verified runtime metadata, user screenshots, exact pasted labels, or authoritative current first-party information applicable to the user's actual environment.

## Privacy

TEMO Efficiency does not silently upload conversations, prompts, screenshots, code, logs, account data, provider catalogs, or telemetry. Feedback is opt-in and should contain only the minimum reproducible evidence.

## Core principle

> Use the smallest capable model. Preserve the acceptance criteria. Escalate only when evidence says you need to.
