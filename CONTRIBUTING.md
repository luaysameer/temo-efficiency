# Contributing to TEMO Efficiency

Contributions are welcome.

The most useful contributions are evidence-driven:

- a real task where the router selected too strong a profile
- a real task where it selected too weak a profile
- a better scoring rule with reproducible examples
- a checkpoint template improvement that reduces repeated context
- a regression-protection pattern that prevents rework

Please keep the core guarantees intact:

1. Never reduce acceptance criteria merely to save usage.
2. Never claim quota/billing bypass.
3. Prefer capability profiles over hardcoded model branding.
4. Escalate based on evidence.
5. Preserve verified work.

When proposing a routing change, include the old score, proposed score, selected profile, and why the change improves cost/quality balance.
